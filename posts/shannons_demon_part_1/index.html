Introduction

If intuition is to be believed, it shouldn’t be possible for a long-only portfolio to be profitable when each of its component assets is a major loser, unless, of course, one is clairvoyant and knows in advance when each asset will happen to perform well. Yet, as I’ll demonstrate in this post, not only is this possible but also an investor can (almost surely) guarantee an exponential amount of money in the long run from such a portfolio, if he knows what he’s doing. As I’ll show, information theory provides a lovely explanation for why this is the case.

The setup

Consider a two-asset portfolio consisting of a riskless asset and a risky asset. We will think of the riskless asset as analogous to a Swiss bank account: the account is so safe and so desirable that it pays a negative interest rate. Therefore, its associated gross return satisfies \(r < 1\). In the example below, I’ll set \(r = 0.97\), which corresponds to a negative interest rate of 3% per period.

On the other hand, the risky asset, which I’ll model as a coin flip, will be highly volatile in its outcome, where heads comes with a very handsome return and tails with a very steep loss. When the coin flip comes up heads, the risky asset will have a gross return of \(\gamma_h\) for heads and \(\gamma_t < \gamma_h\) for tails. In addition, I’ll let \(p_h\) denote the probability of heads, and I’ll set \(\gamma_t = 1/(\alpha \gamma_h)\), for some \(\alpha > 0\). In the example below, I choose \(\gamma_h = 2.0\), \(p_h = 0.5\), and \(\alpha = 1.25\), which implies that \(\gamma_t = 0.4\).

Finally, I let \(f\) denote the fraction of our money that we allocate to the risky asset, and \(1 - f\) the fraction that we allocate to the riskless asset. Our goal is to choose \(f\) intelligently.

Some initial remarks

  1. We need to have \(\gamma_t < r < \gamma_h\) for the problem to be interesting, as otherwise one would put all of one’s money in the better asset. Concretely, if \(r < \gamma_t < \gamma_h\), then one would put all of one’s money in the risky asset, and if \(\gamma_t < \gamma_h < r\), then one would put all of one’s money in the riskless asset. Since our bank account pays negative interest, we have \(\gamma_t < r < 1 < \gamma_h\).
  2. With these parameters, the expected gross return of the risky asset in a given period is given by \[\mathbb{E}[\gamma] = p_h \gamma_h + (1 - p_h) \gamma_t = 1.2.\] Not bad at all!
  3. In addition, notice that the gross return of our portfolio in a given period is given by \[Y(f) = (1 - f)r + f\gamma,\] where \(\gamma\) is the random gross return of the risky asset; thus, in expectation, our portfolio’s gross return is given by \[\mathbb{E}[Y(f)] = (1 - f)r + f\mathbb{E}[\gamma] = 0.97 + 0.23f,\] which is greater than 1 for any \(f > 0.13\). So, we can get an expected gross return greater than 1 by putting some (specifically \(f > 0.13\)) of our money in the risky asset.

The risky asset is a major loser

Obviously the riskless asset is a long-term loser, as its net return is \(r - 1 = -0.03 < 0\) per period. While it is less obvious, as its expected return is quite good (recall \(\mathbb{E}[\gamma] = 1.2\)), the risky asset is also a long-term loser, which is easily seen from Monte Carlo simulations:

  1. Because I chose \(\alpha > 1\), however, the geometric mean of the risky asset’s gross returns is much more sobering: \[\exp(\mathbb{E}[\log \gamma]) = 0.8944 < 1.\]
